# Real-Data EDA & ML Pipeline

Source: Smart Agriculture Dataset — Chaitanya Gopidesi, Kaggle: https://www.kaggle.com/datasets/chaitanyagopidesi/smart-agriculture-dataset

The public dataset has 16,411 records and includes soil type, seedling stage, moisture index (MOI), temperature, humidity and irrigation result. The raw CSV is not generated by this repository.

## Pipeline
1. Acquire the public CSV.
2. Validate columns and target states.
3. Remove exact duplicates and coerce numeric sensor fields.
4. EDA: missing values, duplicates, class distribution, distributions, categorical counts, correlation and feature-vs-target plots.
5. Stratified 80/20 train/test split.
6. Preprocess numeric fields with median imputation + StandardScaler; categorical fields with most-frequent imputation + OneHotEncoder.
7. Train Random Forest inside one sklearn Pipeline.
8. Evaluate only on the untouched test set: accuracy, macro F1, classification report and confusion matrix.
9. Export the fitted pipeline as root irrigation_model.pkl.

## Run
Place the real CSV at eda/data/raw/smart_agriculture_dataset.csv, then from repository root run:

python eda/real_irrigation_pipeline.py --data eda/data/raw/smart_agriculture_dataset.csv

or python train_model.py --data eda/data/raw/smart_agriculture_dataset.csv

Metrics must come from your own run on the real dataset; none are hard-coded. The model predicts irrigation state, not litres. Water quantity remains a separate agronomic/business-logic layer until measured irrigation-volume data is introduced.
